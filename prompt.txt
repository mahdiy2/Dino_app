Write a script that processes a folder of images and validates/fixes them according to the following requirements.

Requirements for each image:

1. Maximum resolution:
- The width and height of the image must not exceed 3000 pixels.
- If either dimension is larger than 3000 pixels, resize the image proportionally so that the largest dimension becomes 3000 pixels while preserving aspect ratio.

2. Allowed aspect ratios:
- Only the following aspect ratios are allowed:
  - 16:9
  - 9:16
- If the image does not match one of these ratios, adjust it by adding white padding (background) around the image until it matches the nearest valid ratio.
- The original image must remain centered and must not be cropped.

3. File size limit:
- The final image file size must not exceed 3 MB.
- If the file is larger than 3 MB, compress it (reduce JPEG quality or use appropriate compression) until it becomes ≤ 3 MB while keeping acceptable visual quality.

4. Padding rules:
- If the image is smaller than the target ratio canvas, expand the canvas by adding white background from the edges until it reaches a valid ratio (16:9 or 9:16).
- Do not distort or stretch the original image.

5. Output:
- Save the processed images in an output folder.
- Keep the original filename.
- Log which images were:
  - resized
  - padded
  - compressed
  - already valid

6. Implementation details:
- Use a common image processing library (e.g., Pillow if using Python, or Sharp if using Node.js).
- Support common formats: JPG, JPEG, PNG, WEBP.
- Skip unsupported files gracefully.

The script should be clean, well‑structured, and able to process all images in a directory automatically.
